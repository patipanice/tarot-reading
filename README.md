# ดูดวงไพ่ยิบซี

เว็บแอปดูดวงไพ่ทาโรต์ภาษาไทย ใช้สำรับ Rider–Waite–Smith ครบ 78 ใบ
ระบบสับไพ่และสุ่มใหม่ทุกครั้งด้วย `Math.random()` ไม่มีการล็อกผลไว้ล่วงหน้า

เป็นเว็บ static ล้วน ๆ ไม่มี build step ไม่มี backend ไม่มีการส่งข้อมูลออกนอกเครื่องผู้ใช้

**เปิดใช้งานจริง:** https://patipanice.github.io/tarot-reading/

## สิ่งที่ทำได้

| หน้า | ทำอะไรได้ |
| --- | --- |
| **ดูดวง** | เลือกเรื่องที่ถาม → เลือกสเปรด → พิมพ์คำถาม (ไม่บังคับ) → กางไพ่ 78 ใบแล้วจั่วเอง → อ่านคำทำนายรายใบพร้อมภาพรวมของสเปรด |
| **ไพ่วันนี้** | เปิดไพ่ประจำวันได้วันละใบ ใบเดิมอยู่ครบวัน แล้วรีเซ็ตเองเมื่อขึ้นวันใหม่ตามเวลาท้องถิ่น |
| **คลังไพ่** | ดูไพ่ทั้ง 78 ใบ ค้นหาด้วยชื่อไทย/อังกฤษ/คำสำคัญ กรองตามดอก และเปิดอ่านความหมายเต็มทั้งหัวตั้งและกลับหัว |
| **ประวัติ** | เก็บผลการดูดวงล่าสุด 50 ครั้งไว้ใน localStorage ของเครื่อง ลบทีละรายการหรือลบทั้งหมดได้ |

สเปรดที่มี: ไพ่ใบเดียว · อดีต-ปัจจุบัน-อนาคต (3 ใบ) · เซลติกครอส (10 ใบ วางเป็นรูปกางเขนจริง ไพ่ใบที่สองวางขวางทับใบแรก)

## วิธีเปิดใช้งานในเครื่อง

เปิดไฟล์ `index.html` ตรง ๆ ได้เลย หรือรัน local server:

```bash
python3 -m http.server 8000 --directory .
```

แล้วเปิด `http://localhost:8000`

## โครงสร้าง

```
index.html               shell + เมนู + คลังสัญลักษณ์ SVG
css/tokens.css           design token (สี ตัวอักษร ระยะ เงา จังหวะ)
css/style.css            layout, ไพ่, พัดไพ่, สเปรด, อนิเมชัน
js/data/cards-major.js   ไพ่ชุดใหญ่ 22 ใบ
js/data/cards-minor.js   ไพ่ชุดเล็ก 56 ใบ
js/data/cards.js         รวมเป็น TAROT_CARDS + findCard()
js/data/spreads.js       นิยามสเปรดและตำแหน่งไพ่
js/data/topics.js        หมวดเรื่องที่ถามได้
js/shuffle.js            Fisher–Yates + สุ่มหัวตั้ง/กลับหัว
js/interpret.js          ประกอบคำแปล + อ่านภาพรวมของสเปรด
js/storage.js            localStorage (ประวัติ + ไพ่ประจำวัน)
js/ui.js                 ตัวช่วยที่ทุกหน้าใช้ร่วมกัน
js/views/*.js            หน้าละไฟล์
js/app.js                เราเตอร์ hash
assets/cards/*.jpg       ภาพไพ่ 78 ใบ
```

ไฟล์ JS โหลดผ่าน `<script>` ธรรมดาตามลำดับ ไม่ใช้ ES module เพื่อให้เปิดผ่าน `file://` ได้โดยไม่ติด CORS

## เรื่องความสุ่ม

- สับไพ่ด้วย Fisher–Yates ใหม่ทุกครั้งที่เริ่มจั่ว
- สุ่มหัวตั้ง/กลับหัวแยกอิสระต่อใบ 50/50
- ไม่มี seed ไม่มีการแคชผล ไม่มี query string ที่กำหนดผลได้
- ไพ่ประจำวันสุ่มจริงตอนกดเปิดครั้งแรกของวัน จากนั้นจึงบันทึกไว้ให้คงที่ทั้งวัน

## คำแปลไพ่

ไพ่ทั้ง 78 ใบมีความหมายเขียนเฉพาะใบ ไม่ได้ประกอบจากสูตร "ดอก + เลข"
แต่ละใบมีความหมายหัวตั้ง ความหมายกลับหัว คำสำคัญของทั้งสองทิศทาง
และมุมมองเฉพาะเรื่องอีก 4 หมวด (ความรัก การงาน การเงิน ภาพรวมชีวิต)
โดยมุมมองรายหมวดเขียนแบบเป็นกลางต่อทิศทางไพ่ จึงอ่านเข้ากันได้ทั้งตอนหัวตั้งและกลับหัว
