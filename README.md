# ดูดวงไพ่ยิบซี

เว็บแอปดูดวงไพ่ยิบซี (ทาโรต์) ภาษาไทย — เลือกหมวดเรื่อง เลือกรูปแบบการดูดวง กรอกคำถาม (ไม่บังคับ) แล้วจั่วไพ่ด้วยตัวเอง ระบบสุ่มไพ่จริงทุกครั้งด้วย `Math.random()` ไม่มีการล็อกผลไว้ล่วงหน้า

เป็นเว็บ static ล้วนๆ (HTML/CSS/JavaScript, ไม่มี build step, ไม่มี backend)

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้โดยตรง (เช่น double-click หรือรันคำสั่ง `open index.html`)

หรือจะรันผ่าน local server เล็กๆ ก็ได้ (ไม่จำเป็น):

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## เครดิตภาพไพ่

ภาพไพ่ทั้ง 78 ใบเป็นชุด Rider–Waite–Smith (วาดโดย Pamela Colman Smith, ตีพิมพ์ปี 1909) ซึ่งเป็นสาธารณสมบัติ (public domain) ในสหรัฐอเมริกา ดาวน์โหลดจาก [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck)

## หมายเหตุ
